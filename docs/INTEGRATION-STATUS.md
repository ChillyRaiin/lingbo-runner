# 当前整合状态与扩展边界

2026-10-10，版本0.3.0。

## 同项目知识库

已调用同项目“搭建 library 知识库”对话，并读取其完成的导出。该对话后续因用量中断，已落盘稳定材料可以独立验证和使用；本项目不依赖该对话继续运行。

适配器读取 `../knowledge-base/exports/knowledge-cards.json`、`sources.json` 和优先版本化的 `retrieval-chunks-v1.jsonl`；输出卡片、来源、条件、查阅层级与许可/审校记录。原PDF、OCR索引、文献库仍在原目录，没有复制入小程序包。

Source ID遵循命名空间，Daniels仅在SHA256与原版匹配时使用原有`daniels-3-cn`；其余书目/论文使用`library-`前缀，卡片使用`kb-`前缀。当前41张概括卡，包含34张扩展卡与7张内置卡。后台加载4908个有效片段，按当前文本长度过滤涉及2822个页位；原库整体覆盖2946页，其中稀少文本、图片和表格需回原页核查。

当前检索采用本地BM25、中英文同义词和课型标题辨析。先用概括卡，多主题比较分别取证；原文默认关闭。没有声称已完成向量嵌入或整库人工审读。知识库导出中的`ai-source-checked-summary`、`machine-unreviewed`、`contentHumanReview`、多来源`citations`和`limits`会保留，不随检索命中升级。

原库稳定导出的6项独立检查已通过。本项目后端知识页、快速检索和Agent使用同一个已整合检索器。更新原库后重建导出并重启服务；尚未加入热更新与后台编辑权限系统。

## 专家 Agent

现有知识卡可在无密钥时检索。DeepSeek适配器使用官方`deepseek-flash`，禁用思考模式以控制交互延迟，并为最终JSON、引用、只读工具、授权、回退和消息隔离做了测试。当前没有真实DeepSeek请求，尚不能评价回答质量或实际调用延迟。

模型不会得到密钥、平台身份、原始Apple健康文件或自动原书全文。用户问题/近期对话和概括卡在显式模型授权后发送；训练摘要另行授权。纯本地原书轮次不进入远程历史。对今日训练的停止/缺失信息情况保留规则结论。模型输出不能写入训练计划或数据库课表。

## Apple健康自动同步

已有小程序连接页、一次性配对接口、限定凭据、增量更新与删除、撤销、身份与数据隔离、三号数据库迁移，以及iOS伴随端源码与Xcode工程。HealthKit API、后台投递 entitlement、启动阶段观察、分批锚点与回执推进逻辑已写入代码。

后端的伪造请求、重发、用户注释保留、交叉用户删除、撤销和过期用例已实际验证。iOS plist/entitlements/scheme已解析校验；本Windows环境没有HealthKit SDK，Swift没有编译，手机权限请求、关联心率查询、后台唤醒与真实数据仍未验证。

实际接通需要真实小程序身份、HTTPS服务、Mac/Xcode构建签名与iPhone安装。默认demo仍只监听电脑回环地址，不能当作手机可访问的服务。当前没有绕过微信或苹果的授权。
